# Sunny Day Photo

架空の出張撮影サービス向けに制作した、1ページ完結型のレスポンシブサイトです。

**公開URL:** https://sunny-day-photo.koikeryota190.chatgpt.site

## 実装内容

- 3種類の撮影プラン
- サービス紹介と利用の流れ
- 開閉式FAQ
- Google Formへの問い合わせ導線
- PC・タブレット・スマートフォン対応
- 基本SEOとアクセシビリティ対応
- 架空サービスであることの明記

## 使用技術

- Next.js / React / TypeScript
- Vinext / Vite
- CSS
- OpenAI Sites

## 主なファイル

- `app/page.tsx`: ページ構造、文章、問い合わせリンク
- `app/globals.css`: デザインとレスポンシブ対応
- `app/layout.tsx`: タイトル、説明文、OGPの基本設定
- `tests/rendered-html.test.mjs`: 主要コンテンツの出力テスト
- `TEST_PLAN.md`: 確認項目と結果

問い合わせ先は、別制作物の「問い合わせ受付自動化システム」で作成したGoogle Formです。サイト閲覧から問い合わせ受付・記録・自動返信までを一連の制作例として構成しています。

## 完成・検証状況

2026年7月13日に公開。本番用ビルド、主要コンテンツ、問い合わせ導線、FAQ、レスポンシブ設計、公開処理、PC・スマートフォン実機表示を確認し、全9項目に合格しました。

## 注意

Sunny Day Photoはポートフォリオ用の架空サービスです。料金・サービス内容・写真は制作例です。

公開サイトで使用している生成画像のバイナリ本体は、リポジトリ容量を抑えるため掲載対象から外しています。ページ構造、デザイン、設定、テストコードは掲載しています。
